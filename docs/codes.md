# GFdash コード・定数定義書

本ドキュメントでは、データベースの `tz901_com_name` およびシステム全体で使用されるコード・定数の定義を管理します。

## 1. 名前マスタ (tz901) コード体系

#### 1.3. アメダス観測地点コード (code: 003)
これらの値は「気象観測地点の設定」画面(910)から変更できます。選択肢は `tz103_weather_station` を参照しています。
| 枝番 (num) | コード名 (code_name) | コード (code_name2) | 備考 |
| :--- | :--- | :--- | :--- |
| 01 | 気象官署prec_no | 44 | 気象官署の都府県・地方のコード(初期値:東京) |
| 02 | アメダスprec_no | 44 | アメダスの都府県・地方のコード(初期値:羽田) |
| 11 | 気象官署block_no | 47662 | 気象官署の観測地点コード(初期値:東京) |
| 12 | アメダスblock_no | 0371 | アメダスの観測地点コード(初期値:羽田) |
| 21 | 官署地点種別 | s | 常に `s` |
| 22 | アメダス地点種別 | a | `s`:気象官署 / `a`:アメダス |

枝番21・22は気象庁の取得先URLの分岐に使用します。気温・風速の取得元には気象官署も

枝番が存在しない場合は `block_no` の桁数（5桁:気象官署 / 4桁:アメダス）で判定します。

「年度期間の設定」画面(912)から変更できます。

| 枝番 (num) | コード名 (code_name) | 設定値 (code_name2) | 備考 |
| :--- | :--- | :--- | :--- |

| :--- | :--- | :--- | :--- |
| 12 | 12〜5月 | 6〜11月 | 上期 |
| 4 | 4〜9月 | 10〜3月 | 下期 |
| 1 | 1〜6月 | 7〜12月 | なし |
| 7 | 7〜12月 | 1〜6月 | なし |

年間来場者数情報詳細(115) / 年間来場者数比較(125) / 年間売上情報詳細(215) /
月間売上比較(220) / 年間売上比較(225) の集計範囲と、グラフの軸ラベル・凡例に
使用します。導出処理は `utils/com_utils.py` に集約しています。

## 3. 権限・フラグ定義 (システム定数)

### 3.1 ユーザー権限レベル (`tz910_permission`)
| 値 | 権限名 | 備考 |
| :--- | :--- | :--- |
| -1 | Hidden | 画面上に表示しない。Admin であっても開けません |
| 0 | Staff | 一般スタッフ（閲覧制限あり） |
| 1 | Manager | 支配人・管理者（全データ閲覧可） |
| 2 | Admin | システム管理者（設定変更可） |

これらの値は「画面の権限設定」画面(920)から変更できます。

### 3.2 権限が未登録の画面の既定値

`tz910_permission` に行が無い画面は、`config_core.py` の `DEFAULT_PERMISSION_LEVELS`
に定義した**画面番号の先頭1桁ごとの既定値**で扱われます。画面を追加するたびに
DBを更新しなくても妥当な権限で動作させるための規定です。

| 画面番号 | グループ | 既定値 |
| :--- | :--- | :--- |
| 0xx | ダッシュボード | 0 (Staff) |
| 1xx | 来場者データ | 0 (Staff) |
| 2xx | 売上データ | 1 (Manager) |
| 3xx | 集計情報 | 1 (Manager) |
| 4xx | AI予測分析 | 1 (Manager) |
| 9xx | メンテナンス | 2 (Admin) |
| 上記以外 | カスタム画面(5xx/8xx)など | 0 (Staff) |

カスタム画面の既定値を変更する場合は `config_custom.py` で
`DEFAULT_PERMISSION_LEVELS` を上書きしてください。

> メンテナンス系(9xx)を Admin にしているのは、定義漏れがそのまま全ユーザーへの
> 公開になるためです。9xx を追加する際は既定値を下げないでください。

### 3.3 権限を変更できない画面

`config_core.py` の `FIXED_PERMISSION_LEVELS` に定義した画面は、DBの値によらず
固定の権限で判定され、920画面からも変更できません。

| 画面 | 固定値 | 理由 |
| :--- | :--- | :--- |
| `920permission_config.html` | 2 (Admin) | 設定を誤ると権限設定画面自体を開けなくなり、DBを直接編集しないと復旧できないため |

固定値には `-1` (Hidden) も指定できます。未完成の画面をコードごと残したまま
確実に閉じたい場合などに使用します。指定した画面は Admin であっても開けません。

### 3.4 時間休業フラグ (`ta220.temp_closed`)
ビット演算による論理和で管理します。
* `1`: 朝休業
* `2`: 昼休業
* `4`: 夜休業
